# Conduit v1.1.0 — Salutation and pronouns Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record how a contact is addressed, and use it where Conduit writes to them.

**Architecture:** Two nullable text columns on `contacts`, a third on `documents` because a quote snapshots its recipient, and two new keys in each of the two merge contexts that already exist. No new mechanism anywhere — every part of this rides something Phase 7 or Phase 4 already built.

**Tech Stack:** Fastify 5, Drizzle (postgres.js), React 19 / TanStack Query, Tailwind v4, Zod, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-29-conduit-contact-salutation-pronouns.md` — the authority.

**Baseline:** `origin/main`, 2374 unit / 0 skipped, 105 e2e. Branch `worktree-v1.1.0-contacts`.

## Conventions every task must follow

Carried from Phase 7, where each of these cost a CI round or a review finding.

- **Migrations are generated, never hand-written, and NEVER `drizzle-kit push`.** Revising an unshipped migration means **regenerating** it (drizzle writes the snapshot, so it cannot drift), restoring the journal's original `when`/`tag`, verifying the journal diff is empty, and then **dropping and recreating `conduit_test`** — the migrator skips by timestamp, so an edited migration is otherwise never re-applied and your tests run against the old shape.
- **`drizzle-kit generate` splits statements on a bare `;`, including one inside a string literal.** A regex in a CHECK containing `;` produces a migration truncated mid-expression. Escape it (`\073`) or avoid it, and read every generated migration end to end.
- **Zod is the gate; the CHECK is the backstop.** Bounds belong in the input schema so a bad value is refused with a message naming the field, not as a 23514 after the fact.
- **A version-specific representation is not a property.** Assert what a thing means, not how one version encodes it.
- **A raw NUL byte turns a source file binary, and every tool then lies to you.** Task 1 put one into `packages/shared/src/index.ts` by meaning `\0` in a comment. `grep -rn` then returns NOTHING for that file, and `git diff` says "Binary files differ" even with `--text`, so the change is unreviewable and blame is broken. It recurred during the fix, because the Edit tool round-trips a raw NUL faithfully: read a line containing one, edit near it, and the byte comes back. **Detect with `od -c` or `grep -clP '\x00'`, never with plain `grep`**, which is blind on a file it has decided is binary.
- **Do not `git checkout -- <file>` to undo a mutation experiment in a file you have also legitimately edited this round.** It reverts to HEAD and silently discards your real work alongside the mutation. Task 1 lost four comment fixes that way and caught it only by luck. Revert the mutation by re-editing it, or stash nothing and re-apply deliberately.
- **Comments must be true.** If you write a number, measure it. Phase 7 corrected false measured numbers ten times.
- **Tailwind v4 scans class names in prose** — a class in a comment is emitted as CSS and moves the stylesheet hash.
- Vitest from the repo root. `CONDUIT_REMOTE_DIR=/home/chris/conduit-phase4 ./scripts/remote.sh '<cmd>'`, that variable EXPLICIT on every server call. ASCII only. `git status` before every push. Targeted `git add`. Conventional commits, `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.

### Task 1: The data model, the API, and both merge contexts

**Files:** `packages/api/src/db/schema.ts`, `packages/api/drizzle/0011_*.sql` (generated), `packages/shared/src/index.ts`, `packages/api/src/services/contacts.ts`, `documents.ts`, and the mail template merge path.

- [ ] **Columns.** `contacts.salutation` and `contacts.pronouns`, both nullable text, bounded at 64 characters by Zod with a CHECK as backstop. **No enum and no CHECK on the value set** — the picker's presets are a UI convenience, and Dhr, Mevr, Drs, Ir, Ing, Rev, Sir and anything in a language nobody has thought of must be typable.
- [ ] **`documents.recipient_salutation`**, populated at issue beside `recipient_name`. **This is the non-obvious part of the release.** A quote is immutable; reading a salutation live would let a contact edit next year rewrite a quote sent last year. Snapshot it, exactly as the name and address already are.
- [ ] **Pronouns are deliberately NOT on `documents`.** A quote's greeting takes the salutation and has no use for pronouns; freezing a personal detail into an artifact that is downloaded and emailed should need a reason. Say so at the column.
- [ ] **Migration 0011.** 0010 is taken by v1.0.1. Read the generated SQL end to end.
- [ ] **The quote merge context** gains `document.recipientSalutation`. **`SEEDED_FIELDS` in `schema.test.ts` is a two-way equality against the migration's seeded template, and Phase 7's `buildContext` key-set test asserts containment** — if you add a key without touching the template, or touch the template without the key, one of them fires. That is the tripwire working; make both agree deliberately.
- [ ] **The mail template context** gains `contact.salutation` and `contact.pronouns` beside the existing `contact.name`, `company.name`, `user.name`. These are **live at compose time** — mail is sent in the moment, so no snapshot and no new storage.
- [ ] **`truncateAll()` destroys the seeded template** (`packages/api/src/test/db.ts`). Any test needing it must seed its own.
- [ ] Verify, commit, push, CI green.

### Task 2: The UI, and three polish items that ride along

**Files:** the contact detail page, the contacts list, `document-form.tsx`, plus the three CSS items.

- [ ] **Contact detail.** Both fields, optional, empty by default. Salutation: a picker of Mr, Mrs, Ms, Mx, Dr, Prof plus "Other..." revealing a text input. Pronouns: he/him, she/her, they/them plus "Other...". A typed value must survive unchanged.
- [ ] **THE RULE, and it needs a test asserting an absence.** Neither field is ever inferred — not from the name, not from the salutation, not from anything. A blank stays blank. Test that a contact with a salutation and no pronouns renders no pronouns anywhere.
- [ ] **The contacts list** shows the salutation beside the name. Pronouns do not appear there — a list is for finding someone, a pronoun is for writing to them.
- [ ] **The quote form's recipient block** picks up the salutation the way it already picks up the name, editable before issuing.
- [ ] **Three items from the Phase 6 findings list, fixed here because this task is already in these files:** the composer's recipient suggestions raised to the 44px floor; the record rail's download link (`components/rail/files.tsx`) given the same floor, which it has never had; and the kanban's stage picker made sticky so switching stages does not mean scrolling back up a long list.
- [ ] Every surface meets the v0.10.0 phone standard. `useIsMobile()` stays closed at three sites; a fourth is a coordinator ruling, not a drift.
- [ ] Build clean **with no CSS warning**; report the stylesheet hash before and after.
