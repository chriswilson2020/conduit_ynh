## Conventions every task must follow

Each of these cost a CI round or a review finding in Phase 7 or v1.1.0.

- **Migrations are generated, never hand-written, and NEVER `drizzle-kit push`.** Revising an unshipped one means regenerating it, restoring the journal's `when`/`tag`, verifying the journal diff is empty, and **dropping and recreating `conduit_test`** — the migrator skips by timestamp.
- **`drizzle-kit generate` splits statements on a bare `;`, including inside a string literal.**
- **Zod is the gate; the CHECK is the backstop.**
- **A raw NUL byte turns a source file binary and every tool then lies to you** — `grep -rn` returns nothing for that file and `git diff` says "Binary files differ" even with `--text`. The Edit tool round-trips one faithfully, so it recurs. **Detect with `od -c` or `grep -clP '\x00'`, never plain `grep`.**
- **Never restore a mutation with `str.replace("", ...)`.** An empty search string matches at position 0, so it PREPENDS rather than inserts and silently corrupts the file. Task 1 did this to `row-link.ts` and caught it only because the result would not parse. Restore by re-editing the exact text, or by keeping a copy of the original.
- **Do not `git checkout -- <file>` to undo a mutation experiment in a file you also edited this round** — it reverts to HEAD and silently discards your real work.
- **A version-specific representation is not a property.** Assert what a thing means, not how one version encodes it.
- **Comments must be true.** If you write a number, measure it. This project has corrected
  false measured numbers **seventeen** times as of Task 2.
